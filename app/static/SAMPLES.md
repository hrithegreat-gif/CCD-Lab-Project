# Bundled demonstration photographs

Downloaded from the scikit-image v0.25.2 data directory and converted to RGB
JPEG at quality 85. Metadata is discarded. No images are hotlinked.

| File | Original | Author / license |
| --- | --- | --- |
| sample-person.jpg | astronaut.png | NASA photograph of Eileen Collins, public domain |
| sample-cat.jpg | chelsea.png | Stefan van der Walt, CC0 |
| sample-coffee.jpg | coffee.png | Rachel Michetti, CC0; courtesy of Pikolo Espresso Bar |

Original files: https://github.com/scikit-image/scikit-image/tree/v0.25.2/skimage/data

Attribution/license descriptions:
https://scikit-image.org/docs/stable/api/skimage.data.html

`loadtest/sample.jpg` is the cat photograph padded/resized to 640 by 480 pixels.
All bundled JPEG files are under 150 KB. These are functional examples, not an
accuracy evaluation dataset.
